# 给新 AI 的开场 prompt（Grok / ChatGPT / Gemini / 豆包 / Kimi …）

换到一个新 AI 时，复制下面这段作为第一条消息。

> ⚠️ 一定要给 **raw 链接**（`raw.githubusercontent.com/...`），不要给仓库首页链接。
> 很多 AI 读 GitHub 网页时拿不到正文，raw 链接是纯文本，最稳。
> 如果这个 AI 不能联网，就直接把 `PROFILE.md` 全文粘贴进去。

---

```
Before we start, please read my personal AI profile (two files):
https://raw.githubusercontent.com/leiyadi87-cpu/yadi-ai-profile/main/PROFILE.md
https://raw.githubusercontent.com/leiyadi87-cpu/yadi-ai-profile/main/THINKING.md

After reading it:
1. Reply in Chinese with a 3–5 line summary of who I am and how I like to work, so I can check you got it right.
2. List anything that seems unclear or that you'd want to ask me.
3. From then on, use this context naturally — don't recite it back to me.

If you can't open the link, tell me directly and I'll paste the file.
```

## 英文版不够用时的中文版

```
开始之前，请先读一下我的个人 AI 档案（两个文件）：
https://raw.githubusercontent.com/leiyadi87-cpu/yadi-ai-profile/main/PROFILE.md
https://raw.githubusercontent.com/leiyadi87-cpu/yadi-ai-profile/main/THINKING.md

读完后：
1. 用 3–5 行中文总结你理解的我（我是谁、我怎么工作），让我核对；
2. 列出你觉得不清楚、想问我的地方；
3. 之后自然地用这些背景，不要每次复述。

如果打不开链接，直接告诉我，我会把文件内容贴给你。
```
